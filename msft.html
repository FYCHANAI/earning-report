一、我們的觀點

🎯

核心經營結論

  • 1.
    Azure 增長加速至 +43%，年營收首破千億美元里程碑

    本季 Azure 及其他雲端服務營收年增 43%，全財年 Azure 營收首次突破 1,000 億美元（年增 41%）。管理層對 FY27 Q1 給出固定匯率約 +45% 之增速指引，並預期 FY27 上半年增速較 FY26 下半年加快。我們認為 AI 與非 AI 工作負載需求同步放量、且在千億美元高基數上不減速，是本季最關鍵的基本面訊號。

  • 2.
    AI 商業化縱深擴大：Copilot 逾 3,000 萬付費席次、商業 RPO 大增 84%

    Microsoft 365 Copilot 付費席次突破 3,000 萬；商業剩餘履約義務 (RPO) 年增 84% 至 6,780 億美元（含 OpenAI 之 Azure 用量承諾；剔除 OpenAI 後商業訂單額仍年增 18%）。我們認為席次訂閱疊加按用量計價的雙引擎模式，正將 AI 需求轉化為高能見度的長約收入。

  • 3.
    資本開支高峰下利潤率展現韌性，惟自由現金流承壓

    本季資本開支（含融資租賃）約 410 億美元，自由現金流降至 196 億美元；2026 曆年資本開支預期約 1,750 億美元（已反映資料中心與辦公大樓使用年期自 15 年延長至 25 年、部分融資租賃轉列營運租賃之分類影響，公司表明基礎投資預期不變）。同期營業利益率仍微升至約 45%，FY27 Q1 指引亦預期大致持平。我們認為市場焦點將由「投資規模」轉向「折舊消化與投資回報節奏」。

  • 4.
    估值：較 ANR 共識目標價具 42.6% 上行空間，前瞻本益比低於大型科技同業

    以 2026/07/29 收盤價 US$390.54 計，較 Bloomberg ANR 12 個月共識目標價 US$556.88（截至 2026/07/30）具 42.6% 上行空間。我們認為在 EPS 高增長與 Azure 加速的組合下，現價之風險回報具吸引力。

高盛 (Goldman Sachs)

  • Copilot 規模化驗證 AI 貨幣化模式： Microsoft 365 Copilot 付費席次逾 3,000 萬，席次訂閱疊加按用量計價，為每席 ARPU 與滲透率提供雙重上行空間。

  • 資本開支回報節奏為關鍵觀察點： 2026 曆年資本開支約 1,750 億美元，Microsoft Cloud 毛利率同比降至 65%，折舊上行對毛利率之影響需持續追蹤。

五、風險因素

  1. AI 基礎設施投資回報之不確定性： FY27 Q1 資本開支指引逾 500 億美元、2026 曆年約 1,750 億美元；本季公司毛利率 67.2% 已因 Azure 佔比上升與 AI 基建投入而同比下降，Microsoft Cloud 毛利率降至 65%。若 AI 需求增速放緩，折舊攀升與產能閒置恐進一步壓縮利潤率。
  2. OpenAI 相關損益與合約集中度風險： OpenAI 投資影響全財年為淨收益 49.63 億美元（EPS +$0.67）、本季為 +4.8 億美元，屬非經營性損益且方向與金額波動劇烈，可能放大 GAAP 業績波動；商業訂單額含 OpenAI 之 Azure 用量承諾（含其在內年增 10%、剔除後年增 18%），單一大客戶承諾之履約情況值得持續關注。
  3. 個人運算業務持續承壓： 本季個人運算營收年減 4%，其中 Windows OEM 與裝置年減 7%、XBOX 內容與服務年減 10%，季內並已認列 XBOX 減損與遣散費；FY27 Q1 指引 Windows OEM 與裝置降幅擴大至百分之二十出頭 (low-twenties)。
  4. 監管審查與雲端競爭風險： 微軟於雲端與 AI 領域面臨全球反壟斷與 AI 治理之監管審查；同業於 AI 基礎設施之投資同樣進取，算力供給與價格競爭可能影響 Azure 增速與定價能力。
