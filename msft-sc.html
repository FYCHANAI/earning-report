一、我们的观点

🎯

核心经营结论

  • 1.
    Azure 增长加速至 +43%，年营收首破千亿美元里程碑

    本季 Azure 及其他云服务营收同比增长 43%，全财年 Azure 营收首次突破 1,000 亿美元（同比 +41%）。管理层对 FY27 Q1 给出固定汇率约 +45% 之增速指引，并预期 FY27 上半年增速较 FY26 下半年加快。我们认为 AI 与非 AI 工作负载需求同步放量、且在千亿美元高基数上不减速，是本季最关键的基本面信号。

  • 2.
    AI 商业化纵深扩大：Copilot 逾 3,000 万付费席位、商业 RPO 大增 84%

    Microsoft 365 Copilot 付费席位突破 3,000 万；商业剩余履约义务 (RPO) 同比增长 84% 至 6,780 亿美元（含 OpenAI 之 Azure 用量承诺；剔除 OpenAI 后商业订单额仍同比增长 18%）。我们认为席位订阅叠加按用量计价的双引擎模式，正将 AI 需求转化为高能见度的长约收入。

  • 3.
    资本开支高峰下利润率展现韧性，惟自由现金流承压

    本季资本开支（含融资租赁）约 410 亿美元，自由现金流降至 196 亿美元；2026 日历年资本开支预期约 1,750 亿美元（已反映数据中心与办公楼使用年限自 15 年延长至 25 年、部分融资租赁转列经营租赁之分类影响，公司表明基础投资预期不变）。同期营业利润率仍微升至约 45%，FY27 Q1 指引亦预期大致持平。我们认为市场焦点将由“投资规模”转向“折旧消化与投资回报节奏”。

  • 4.
    估值：较 ANR 共识目标价具 42.6% 上行空间，远期市盈率低于大型科技同业

    以 2026/07/29 收盘价 US$390.54 计，较 Bloomberg ANR 12 个月共识目标价 US$556.88（截至 2026/07/30）具 42.6% 上行空间。我们认为在 EPS 高增长与 Azure 加速的组合下，现价之风险回报具吸引力。

四、华尔街观点

（评级与目标价：Bloomberg ANR，截至 2026/07/30）

高盛 (Goldman Sachs)

买入 (Buy)
  • AI 平台周期的核心受益者（目标价 US$640）： Azure 同比增长 43%、全财年首破 1,000 亿美元，商业 RPO 同比增长 84% 至 6,780 亿美元，企业 AI 支出正向微软平台集中，收入能见度居大型科技同业前列。
  • Copilot 规模化验证 AI 货币化模式： Microsoft 365 Copilot 付费席位逾 3,000 万，席位订阅叠加按用量计价，为每席 ARPU 与渗透率提供双重上行空间。

花旗 (Citi)

买入 (Buy)
  • 云端动能延续至新财年（目标价 US$570）： FY27 Q1 总营收指引 898.5 亿至 909.5 亿美元、Azure 固定汇率约 +45%，显示增长动能在高基数上仍在加速。
  • 高强度投资期的利润率管理优于同业： 本季营业利润率约 45% 并同比微升，FY27 Q1 指引预期营业利润率大致持平，总人数同比减少 2%，展现费用纪律。

巴克莱 (Barclays)

增持 (Overweight)
  • 长约锁定支撑多年营收曲线（目标价 US$545）： 商业 RPO 达 6,780 亿美元、剔除 OpenAI 后商业订单额同比增长 18%，为未来数年云端收入提供高度锁定基础。
  • 资本开支回报节奏为关键观察点： 2026 日历年资本开支约 1,750 亿美元，Microsoft Cloud 毛利率同比降至 65%，折旧上行对毛利率之影响需持续追踪。

五、风险因素

  1. AI 基础设施投资回报之不确定性： FY27 Q1 资本开支指引逾 500 亿美元、2026 日历年约 1,750 亿美元；本季公司毛利率 67.2% 已因 Azure 占比上升与 AI 基建投入而同比下降，Microsoft Cloud 毛利率降至 65%。若 AI 需求增速放缓，折旧攀升与产能闲置恐进一步压缩利润率。
  2. OpenAI 相关损益与合约集中度风险： OpenAI 投资影响全财年为净收益 49.63 亿美元（EPS +$0.67）、本季为 +4.8 亿美元，属非经营性损益且方向与金额波动剧烈，可能放大 GAAP 业绩波动；商业订单额含 OpenAI 之 Azure 用量承诺（含其在内同比 +10%、剔除后同比 +18%），单一大客户承诺之履约情况值得持续关注。
  3. 个人计算业务持续承压： 本季个人计算营收同比下降 4%，其中 Windows OEM 与设备同比下降 7%、XBOX 内容与服务同比下降 10%，季内并已计提 XBOX 减值与遣散费用；FY27 Q1 指引 Windows OEM 与设备降幅扩大至百分之二十出头 (low-twenties)。
  4. 监管审查与云计算竞争风险： 微软于云计算与 AI 领域面临全球反垄断与 AI 治理之监管审查；同业于 AI 基础设施之投资同样进取，算力供给与价格竞争可能影响 Azure 增速与定价能力。
