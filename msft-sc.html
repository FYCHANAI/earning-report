一、我们的观点

核心经营结论

  • 1.
    Azure 加速增长，平台效率提升扩大 AI 收入承接能力

    Azure 本季营收增长 48%，公司预计下一季按固定汇率再增长 49–50%。我们认为，微软的优势不止于扩建算力，更在于将企业软件、资料平台与 AI 服务整合，提升现有基建的使用效率及每个客户的收入贡献。这有助于在供应仍受限制时维持增长，但季度表现仍会受新产能交付节奏影响。

  • 2.
    云端及订阅收入支撑盈利质素，核心增长仍具韧性

    Microsoft Cloud 营收达 US$63.9bn，年增 30%；Microsoft 365 商业云收入按列报基准增长 17%。我们认为，企业长期订阅关系与云端用量形成互补，为 AI 商业化提供较稳定的收入基础。本季剔除 OpenAI 投资影响后 EPS 为 US$4.89、年增 18%，较 GAAP 的 32% 增幅更能反映核心业务的盈利趋势。

  • 3.
    现金创造能力强，但投资回报仍是估值的关键

    本季营运现金流 US$58.0bn，扣除现金购置物业及设备 US$39.367bn 后，自由现金流为 US$18.633bn。我们认为，强劲现金流支持微软持续投资 AI，但资本开支加快亦提高市场对新增产能变现效率的要求；后续应重点观察云端毛利率与自由现金流能否随收入规模同步改善。

  • 4.
    估值反映优质增长，回报取决于业绩持续兑现

    Bloomberg 显示未来四季 P/E 为 25.60x，介乎所列大型科技同业之间；共识目标价 US$634.56 相对 10/29 参考股价 US$530.14 隐含约 19.7% 上行。我们认为，微软的企业客户基础及多层次 AI 变现能力支持估值溢价，但持续重估仍需由 Azure 增长、Copilot 收入及投资回报共同验证，不能只依赖目标价差距。

五、风险因素

  1. AI 投资与现金回报风险：持续扩充资料中心、CPU 及 GPU 将增加折旧与营运负担；若新增需求或产能利用率不及预期，利润率及自由现金流可能受压。
  2. 产能交付及增长波动：第三方算力交付延后，加上平台效率改善及模型组合变化，可能令 Azure 季度增长波动；短期高增速不宜直接外推。
  3. 企业软件竞争与 AI 变现：Copilot 的付费渗透率、用量收入及续约表现仍须持续验证。竞争、价格压力及客户对回报的要求，可能影响每客户收入增长。
  4. 投资损益、消费业务与监管：OpenAI 投资损益可放大 GAAP 盈利波动；Windows OEM 与装置收入本季下跌 22%，消费业务复苏仍有不确定性。云端、AI、私隐及网络安全监管亦可能增加成本或限制产品发展。
